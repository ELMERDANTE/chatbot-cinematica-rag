# prompts/

Plantillas versionadas del prompt pedagógico.

- `tutor_v0.1.txt`: plantilla inicial del tutor socrático con RAG.

## Reglas

- Cada cambio genera una nueva versión (`tutor_v0.2.txt`, …); no se sobrescriben versiones anteriores.
- La plantilla se congela antes de la evaluación final.
- La línea base sin RAG usa la misma plantilla, sin el bloque CONTEXTO y sin la regla 1.
